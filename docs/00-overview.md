# Fielddesk 站点手册

## 目标
- 让 Fielddesk 保持研究型内容站的气质
- 让信息架构、视觉语言、栏目职责和写作模板可复用
- 让后续改版不靠记忆，靠文档

## 这一组文档怎么用
- 先看 `01-design-system.md`
- 再看 `02-ia-and-pages.md`
- 写内容前看 `03-editorial-model.md` 和 `04-templates.md`
- 涉及引用时看 `05-sources-policy.md`
- 上线前看 `06-launch-checklist.md`

## 站点原则
- 克制
- 清晰
- 可核验
- 长文友好
- 静态优先

## 不做的事
- 不做数据库
- 不做登录
- 不做会员墙
- 不做 CMS 后台
- 不做营销式首页
