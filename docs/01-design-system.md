# 设计规范

## 基础布局
- 页面最大宽度：`1140px`
- 正文最大宽度：`720px`
- 右侧辅助栏：`280px`
- 桌面左右安全边距：`32px`
- 平板：`24px`
- 手机：`20px`

## 字号
- H1：`44px / 1.15`
- H2：`28px / 1.25`
- H3：`20px / 1.3`
- 正文：`17px`
- 辅助说明：`14px`
- 眉注：`12px`
- 卡片摘要：`15px`

## 行距与间距
- 正文行高：`1.75`
- 段落间距：`16px`
- 模块间距：`24px`
- 区块间距：`32px`
- 大区块间距：`48px`
- 首页首屏留白：`64px`
- 统一 8px 基线

## 颜色
- 页面底色：`#f7f8fb`
- 内容面板：`#ffffff`
- 轻背景：`#f1f5f9`
- 主文字：`#111827`
- 次文字：`#5b6472`
- 分割线：`#d7dee8`
- 强分割线：`#b8c4d3`

## 专栏强调色
- 行业观察：`#1d4ed8`
- 公司研究：`#0f766e`
- 人物研究：`#b45309`
- 行业专题：`#166534`

## 组件节奏
- 首页卡片：1 个重点卡 + 3 到 4 个最新卡
- 推介页：精选优先，不按栏目分组
- 专栏页：列表化，便于扫读
- 文章页：标题、摘要、正文、来源、相关阅读
